- 미들웨어
    
    미들웨어(Middleware)는 요청(Request)과 응답(Response) 사이에서 실행되는 중간 처리 함수
    
    클라이언트의 요청이 서버에 도달하기 전 또는 응답이 반환되기 전에 공통적인 작업을 수행할 수 있도록 도와줌
    
    주요 역할:
    
    - 요청 데이터 처리
    - 인증 및 권한 검사
    - 로그 출력
    - 에러 처리
    - JSON 파싱
    
    Express에서는 `app.use()`를 통해 미들웨어를 등록할 수 있음
    
- HTTP 상태 코드
    
    HTTP 상태 코드는 서버가 클라이언트의 요청 처리 결과를 숫자로 표현한 코드
    
    클라이언트는 상태 코드를 통해 요청 성공 여부나 에러 상황을 확인할 수 있음
    
    주요 상태 코드:
    
    - `200 OK`: 요청 성공
    - `201 Created`: 리소스 생성 성공
    - `400 Bad Request`: 잘못된 요청
    - `401 Unauthorized`: 인증 실패
    - `403 Forbidden`: 권한 없음
    - `404 Not Found`: 리소스를 찾을 수 없음
    - `500 Internal Server Error`: 서버 내부 오류
    
    장점:
    
    - 클라이언트가 요청 결과를 명확히 파악 가능
    - 프론트엔드와 백엔드 간 통신 규칙 통일 가능
    - 에러 상황을 체계적으로 관리 가능
- 에러 핸들링(Error Handling)
    
    에러 핸들링은 프로그램 실행 중 발생하는 예외 상황을 감지하고 적절히 처리하는 과정
    
    서버에서는 잘못된 요청이나 DB 오류 등이 발생할 수 있으므로, 이를 공통적으로 처리하는 구조가 중요함
    
    Express에서는 전역 에러 핸들러를 통해 에러를 처리할 수 있음
    
- Tsoa
    
    Tsoa는 TypeScript 기반으로 OpenAPI(Swagger) 문서를 자동 생성해주는 라이브러리
    
    TypeScript 타입과 데코레이터를 기반으로 API 라우팅과 문서화를 동시에 처리할 수 있음
    
    주요 데코레이터:
    
    - `@Route`: API 기본 경로 설정
    - `@Get`, `@Post`: HTTP 메소드 정의
    - `@Body`, `@Path`, `@Query`: 요청 데이터 정의
    - `@Tags`: Swagger 그룹화
    - `@SuccessResponse`: 성공 응답 정의
