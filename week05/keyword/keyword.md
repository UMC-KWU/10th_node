- 환경 변수
    
    : 프로그램 외부에서 설정하는 값. 코드 실행 환경에 따라 달라질 수 있는 설정 정보이다.
    
    db비밀번호, 서버 포트 등이 예시이다.
    
    코드와 분리되어 관리되며, 민감한 정보를 보호할 수 있다는 장점이 있다. 
    
- CORS
    
    : 다른 출처에서의 요청을 제한하거나 허용하는 브라우저 보안 정책이다.
    
    서버에서 허용 여부를 설정하고, 브라우저에서만 적용된다.
    
    설정이 없으면 정상 요청도 차단될 수 있다.
    
- DB Connection, DB Connection Pool
    
    : DB Connection은 DB와의 단일연결이고 Connection Pool은 여러개의 연결을 미리 생성하고 재사용 하는것이다. Pool은 연결을 재사용하므로 성능이 향상되고 동시에 여러 요청을 처리할 수 있다.
    
    메모리 사용이 증가하거나 리소스 낭비가 되는 등의 단점도 존재할 수 있다.
    
- 비동기 (async, await)
    
    : 시간이 오래 걸리는 작업을 효율적으로 처리하기 위한 방식이다.
    
    동기 코드처럼 순서대로 작성이 가능하다. 
    
- try/catch/finally
    
    : 코드 실행 중 발생하는 오류를 처리하는 구조.
    
    try(실행), catch(에러 처리), finally(항상 실행)으로, 예외 발생시 프로그램이 종료되는것을 방지하는 구조이다.
    
- Interface(인터페이스)
    
    : 객체의 구조(속성, 타입)을 정의하는 Typescript문법
    
    타입 체크 목적으로 쓰이며 실제 값은 포함하지 않는다.
    
- Type Assertion(as 키워드)
    
    : 개발자가 특정 값의 타입을 명시적으로 지정하는 문법
    
    예를 들어 const value=data as string;
    
    컴파일 단계에서만 적용되며 타입 오류를 해결할 수 있는 한편, 안정성이 감소될 수 있다.
